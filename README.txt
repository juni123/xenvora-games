XENVORA GAMES LLP website files

FILES
- index.html: website structure and page content
- style.css: responsive design and styling
- script.js: mobile navigation, current year, and reveal animations

HOW TO USE
1. Extract the ZIP file.
2. Upload index.html, style.css, and script.js into the same folder in your hosting File Manager / cPanel (usually public_html).
3. Open your domain to check the website.

CUSTOMIZE BEFORE PUBLISHING
- The contact button currently uses hello@xenvoragames.com. Replace this with your real business email in index.html if needed.
- The game cards are illustrative categories, not links to specific released games. Replace them with your real game titles, images, and store links.
- Google Fonts are loaded online; if unavailable, fallback fonts will be used.
